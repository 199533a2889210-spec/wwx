# Lacklabor Master Learning System

双击 `index.html` 即可离线使用。答案、章节位置、错题、实验和掌握进度都保存在浏览器本机。

## 六种学习模式

1. 学习模式：解释前10章为什么按当前顺序讲、核心知识路径、易混淆点和后续关联。
2. 教授问答：340道中德双语题，严格按基础、原理、结构、反应、配方、实验、性能、应用、教授追问排序。
3. 化学结构：收录LS01–LS10中的113种明确化合物、代表性聚合物链段、催化剂、引发剂、溶剂、添加剂与无机物。默认使用大学教材和ACS论文常见的标准二维结构：规则环形、标准键角、平行双键，并省略碳骨架标签及与碳相连的氢。结构由专业二维化学绘图库从SMILES生成SVG，可无损缩放。
4. 实验模式：保留前10章相关的关键实验/工艺决策模拟，每一步解释为什么做、做错会怎样。
5. 知识网络：仅显示LS01–LS10之间的依赖关系，可点击章节跳转。
6. 考试模式：顺序口试、50组五层 Warum 追问（共250层）、错题与薄弱章节统计。

五层追问覆盖前10章，每章5组。LS01、LS03、LS04、LS05、LS08、LS10等反应章节附带课件机理重绘，标出进攻原子/官能团、电子移动、键形成与断裂、中间体和副产物。

## 化学结构说明

- 默认模式是 `ChemDraw 2D` 风格的标准二维出版式，不再使用自动原子图或力导向布局。
- 结构来源严格按“课件原结构 > ChemDraw导出SVG/Molfile/CDX转换结果”的顺序选择。课件结构一旦录入，系统直接保留其原始键角、方向、标注和排布，不对其进行坐标优化或自动补全。
- 每次显示都会读取SVG内容的实际边界框，保持比例自动居中，并加入10%的安全边距；因此结构通常占可视区域约83%，不会因为分子大小不同而被裁切或只显示一部分。
- 聚合物、技术级混合物、异构体混合物及金属催化剂不存在唯一的单分子结构；这类条目会明确标记为“代表结构”，避免把不确定组成伪装成唯一结构。
- Lewis和3D按钮保留为后续专业渲染器入口；在相应渲染器接入前不会调用近似绘图冒充专业结构。
- 结构数据保存在 `chemical-data.js`，专业二维绘制逻辑保存在 `publication-chemistry.js`，便于继续逐页补充或校订。

## 扩充题库

编辑 `questions.js`，在 `QUESTION_BANK` 数组中复制一个题目对象并修改：

- `id`：唯一编号
- `chapter` / `title`：章节号与名称
- `kind`：基础、机理、实验、配方、应用等
- `source`：课件页码
- `qDe` / `qZh`：德语问题与中文翻译
- `answer`：德语标准答案
- `analysis`：中文解析
- `why`：为什么老师问
- `ifNot`：不这样做的后果
- `links`：关联章节
- `keywords`：自动对比使用的德语核心词
- `tags`：页面标签
- `followUpOf`：追问填写主问题 id；并把对象紧放在主问题后

`generated-questions.js` 由 `tools/build_full_bank.py` 根据课件逐页生成。人工精编题保存在 `questions.js`。

本应用不上传数据，也不需要网络。
